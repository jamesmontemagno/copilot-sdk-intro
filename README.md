# Copilot SDK Intro

Standalone live-demo samples for the GitHub Copilot SDK.

Each folder contains starter code and a language-specific `LIVE_DEMO.md` that presenters can follow live:

| Language | Folder | Run |
| --- | --- | --- |
| .NET | `dotnet` | `dotnet run --project dotnet` |
| Node.js | `nodejs` | `cd nodejs; npm install; npm start` |
| Python | `python` | `cd python; pip install -r requirements.txt; python main.py` |
| Go | `go` | `cd go; go run .` |
| Java | `java` | `cd java; mvn compile exec:java` |
| Rust | `rust` | `cd rust; cargo run` |

Authenticate first if needed:

```powershell
copilot auth login
```
